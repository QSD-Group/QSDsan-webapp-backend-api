# QSDsan-webapp-backend-api — RETIRED

> ⚠️ **This repository is retired and archived (read-only).**

This was an early **Flask** backend for the NJ Bioenergy Calculator. It has been
**superseded by the FastAPI service** in
[`nj-bioenergy-api`](https://github.com/QSD-Group/nj-bioenergy-api) (formerly
`QSDsan-api`), which runs in production at https://api.qsdsan.app.

Use `nj-bioenergy-api` for all backend work. This repo is kept only for history.
